# 🌍 PyInfos : Météo & Infos

Un petit programme Python qui affiche la **météo** et les **dernières actualités** françaises dans une interface graphique simple et agréable.  
Il utilise :

- 🌤️ **Open-Meteo** pour la météo (aucune clé API nécessaire)  
- 📰 **Google News RSS** pour les actualités  
- 🖥️ **Tkinter** pour l’interface graphique  

---

## 🛠️ Fonctionnalités

- Affiche la **météo actuelle** d’une ville avec température et vent  
- Affiche les **prévisions sur 3 jours**  
- Affiche les **5 dernières actualités** françaises  
- Interface simple et moderne avec **emojis** pour plus de lisibilité
